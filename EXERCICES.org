* Mode d'emploi (lis-moi d'abord)
** Comment lire ce fichier
Ce fichier est en *Org*, le format de notes d'Emacs. Tout se fait au clavier :

| Touche                 | Effet                                                            |
|------------------------+------------------------------------------------------------------|
| =TAB= sur un titre       | déplie / replie ce titre                                          |
| =S-TAB= (Shift+Tab)      | déplie / replie tout le fichier                                   |
| =C-c C-o= sur un lien    | ouvre le lien (fichier à l'endroit exact) dans l'autre fenêtre    |
| =C-c C-t= sur un titre   | marque l'exercice =FAIT= (le compteur du chapitre se met à jour)  |

Chaque exercice est une *mission* : une vraie modification de code, comme au travail.
- *Mission* : ce qu'il faut obtenir. Essaie d'abord seul.
- *Vérifier* : une commande qui dit ✅ ou ❌, et ce qui manque.
- *Touches (si tu as oublié)* : sous-titre replié, ouvre-le avec =TAB=. Toutes les
  touches utiles, avec un truc pour les retenir. Ouvre-le sans hésiter : le but est de
  *faire* la mission avec les touches, pas de les connaître par cœur avant.
- *Pas à pas (si tu bloques)* : la solution complète, touche par touche.

À la fin de chaque chapitre, une *révision* reprend les touches du chapitre dans une
nouvelle mission, sans les redonner dans l'énoncé.

** Comment retenir les touches (lis ça, c'est le plus important)
Les touches d'Emacs ne sont pas au hasard. Elles suivent deux logiques. Une fois que tu
les vois, tu peux *deviner* une touche au lieu de la retenir.

*1. La taille : =C-= petit, =M-= plus grand, =C-M-= encore plus grand.*
La lettre dit *quoi faire*, la touche de modification dit *sur quelle taille*.

| Lettre (mot anglais)  | =C-= (caractère / ligne)  | =M-= (mot / phrase)      | =C-M-= (bloc / fonction)      |
|-----------------------+---------------------------+--------------------------+-------------------------------|
| =f= forward (avancer)   | =C-f= un caractère          | =M-f= un mot               | =C-M-f= un bloc ( ) { } [ ]     |
| =b= backward (reculer)  | =C-b= un caractère          | =M-b= un mot               | =C-M-b= un bloc                 |
| =a= (début, 1re lettre) | =C-a= début de la ligne     | =M-a= début de la phrase   | =C-M-a= début de la fonction    |
| =e= end (fin)           | =C-e= fin de la ligne       | =M-e= fin de la phrase     | =C-M-e= fin de la fonction      |
| =k= kill (couper)       | =C-k= jusqu'à fin de ligne  | =M-k= la phrase            | =C-M-k= le bloc entier          |
| =d= delete (effacer)    | =C-d= un caractère          | =M-d= un mot               |                               |
| =h= (sélectionner)      |                           | =M-h= le paragraphe        | =C-M-h= la fonction entière     |

*2. Les préfixes sont des familles.* Tape le préfixe, *attends une seconde* : une
fenêtre (which-key) affiche toutes les suites possibles. Tu n'as donc qu'à retenir la famille.

| Préfixe  | Pense à…                     | Exemples                                               |
|----------+------------------------------+--------------------------------------------------------|
| =C-x=      | Emacs : fichiers, fenêtres   | =C-x C-f= ouvrir, =C-x C-s= sauver, =C-x b= buffer, =C-x 3= couper |
| =C-x p=    | *P*rojet                     | =f= fichier, =b= buffer, =c= compiler, =r= remplacer     |
| =C-x r=    | *R*ectangle, *r*egistres     | =t= texte sur une colonne, =m= / =b= marque-pages        |
| =C-x v=    | *V*ersion (git)              | =n= annuler un changement, =*= voir le diff              |
| =M-g=      | *G*o (aller à)               | =g= ligne, =i= index des fonctions, =e= erreurs          |
| =M-s=      | *S*earch (chercher)          | =l= lignes, =r= ripgrep (projet), =o= occur, =.= symbole |
| =C-c l=    | *L*anguage server            | =r= renommer, =a= actions, =o= imports, =f= formater     |
| =C-h=      | *H*elp (aide)                | =k= une touche, =f= une fonction, =B= toutes les touches |

*3. Trois réflexes quand tu as oublié.*
- Tu connais la famille : tape le préfixe et attends (which-key).
- Tu connais le nom de la commande : =M-x= et quelques lettres. La touche est affichée à droite.
- Tu connais la touche mais pas ce qu'elle fait : =C-h k= puis la touche.

*4. Refais les révisions.* Une touche entre dans la mémoire à long terme quand on la
réutilise *après l'avoir un peu oubliée*. Refais la révision d'un chapitre le lendemain,
puis 3 jours après, puis la semaine suivante (=python3 verifier.py --reset 2.R= la remet à zéro).

** Lire les raccourcis
| Écrit       | Sur ton Mac                                                         |
|-------------+---------------------------------------------------------------------|
| =C-x=         | Ctrl + x                                                            |
| =M-x=         | Option *gauche* + x  (Option droite reste pour taper [ ] { } \vert ~) |
| =s-p=         | Cmd + p                                                             |
| =S-TAB=       | Shift + Tab                                                         |
| =S-<f12>=     | Shift + F12  (sur un MacBook : Fn + Shift + F12)                     |
| =C-x p f=     | Ctrl+x, *relâche*, puis p, puis f  (une séquence, pas en même temps)  |
| =C-u C-SPC=   | Ctrl+u puis Ctrl+Espace                                             |

=C-SPC= (Ctrl+Espace) est aussi le raccourci de macOS pour changer la langue du clavier :
il a été désactivé dans les réglages de ton Mac pour qu'Emacs le reçoive. S'il ne marche
toujours pas, déconnecte-toi de ta session macOS et reconnecte-toi. En attendant, =C-@=
fait exactement la même chose.

Deux réflexes qui sauvent :
- =C-g= annule *tout* (commande en cours, minibuffer, sélection). Dans le doute : =C-g C-g=.
- Une fausse manip : =C-/= annule. Encore =C-/= pour annuler plus loin.

** Préparer ton Emacs
1. Passe sur le profil *minimal* : =C-c P= puis choisis =minimal= (Emacs redémarre).
2. Ouvre ce fichier : =C-x C-f ~/dev/emacs-exercices/EXERCICES.org RET=.
3. Coupe l'écran en deux : =C-x 3=. Les exercices à gauche, le code à droite.
   =C-x o= passe d'une fenêtre à l'autre.

** Vérifier une mission et recommencer
Depuis n'importe quel fichier du projet :
- =C-x p c= (compiler dans le projet), efface la commande proposée (=C-a C-k=),
  tape =python3 verifier.py 2.1= puis =RET=.
- =python3 verifier.py= tout seul vérifie toutes les missions.
- Pour recommencer une mission : =python3 verifier.py --reset 2.1=. Attention, cela remet
  à zéro *les fichiers* de la mission : les autres missions qui utilisent les mêmes
  fichiers sont remises à zéro aussi (par exemple 2.1, 2.2, 2.3 et 2.5 sont toutes dans
  =src/livraison.ts=).
- Pense à sauvegarder (=C-x C-s=) avant de vérifier : le script lit les fichiers sur le disque.

Astuce : dans la commande =C-x p c=, =M-p= rappelle la commande précédente. Pas besoin de la retaper.
