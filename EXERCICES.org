* Mode d'emploi (lis-moi d'abord)
** Comment lire ce fichier
Ce fichier est en *Org*, le format de notes d'Emacs. Tout se fait au clavier :

| Touche              | Effet                                                         |
|---------------------+---------------------------------------------------------------|
| =TAB= sur un titre    | déplie / replie ce titre                                       |
| =S-TAB= (Shift+Tab)   | déplie / replie tout le fichier                                |
| =C-c C-o= sur un lien | ouvre le lien (fichier à l'endroit exact) dans l'autre fenêtre |
| =C-c C-t= sur un titre | marque l'exercice =FAIT= (le compteur du chapitre se met à jour) |

Chaque exercice contient :
- *Situation* : le cas réel de tous les jours.
- *À faire* : l'objectif précis.
- *Comment faire* : un sous-titre replié. Essaie d'abord sans l'ouvrir, puis ouvre-le avec =TAB=.
- *Vérifier* (quand c'est possible) : une commande qui dit ✅ ou ❌.

** Lire les raccourcis
| Écrit     | Sur ton Mac                                                       |
|-----------+-------------------------------------------------------------------|
| =C-x=       | Ctrl + x                                                          |
| =M-x=       | Option *gauche* + x  (Option droite reste pour taper [ ] { } \vert ~) |
| =s-p=       | Cmd + p                                                           |
| =S-<f12>=   | Shift + F12  (sur un MacBook : Fn + Shift + F12)                   |
| =C-x p f=   | Ctrl+x, *relâche*, puis p, puis f  (une séquence, pas en même temps) |
| =C-u C-SPC= | Ctrl+u puis Ctrl+Espace                                           |

Deux réflexes qui sauvent :
- =C-g= annule *tout* (commande en cours, minibuffer, sélection). Dans le doute : =C-g C-g=.
- Tape le début d'un raccourci (ex. =C-x=) et attends 1 seconde : *which-key* affiche toutes les suites possibles.

** Préparer ton Emacs
1. Passe sur le profil *minimal* : =C-c P= puis choisis =minimal= (Emacs redémarre).
2. Ouvre ce fichier : =C-x C-f ~/emacs-exercices/EXERCICES.org RET=.
3. Coupe l'écran en deux : =C-x 3=. Les exercices à gauche, le code à droite.
   =C-x o= passe d'une fenêtre à l'autre.

** Vérifier un exercice et recommencer
Depuis n'importe quel fichier du projet :
- =C-x p c= (compiler dans le projet), efface la commande proposée (=C-a C-k=),
  tape =python3 verifier.py 4.1= puis =RET=.
- =python3 verifier.py= tout seul vérifie tous les exercices.
- Pour recommencer un exercice : =python3 verifier.py --reset 4.1=.
  Attention, les exercices qui modifient le même fichier sont remis à zéro ensemble
  (4.4, 5.3 et 5.5 travaillent tous dans =src/notes.ts=).

Astuce : dans la commande =C-x p c=, =M-p= rappelle la commande précédente. Pas besoin de la retaper.

** TODO 1.2 Passer d'un fichier ouvert à l'autre
*Situation* : tu as 5 fichiers ouverts et tu jongles entre eux.
*À faire* : ouvre 3 fichiers, puis reviens à chacun sans la souris. Ferme-en un.
*Équivalent VS Code* : Ctrl+Tab, Cmd+W.

*** Comment faire
- =C-x b= : liste des buffers (fichiers ouverts) avec *aperçu en direct* quand tu bouges.
  =C-x b RET= tout de suite = retour au fichier précédent. C'est le raccourci le plus utilisé.
- =C-x p b= : seulement les buffers du projet courant.
- Dans =C-x b=, tape =<= puis une lettre pour filtrer : =< b= les buffers, =< f= les

** TODO 4.2 Renommer un nom partout, même hors du code (YAML, Bash, Python)
*Situation* : la clé =api_url= devient =base_url=. Elle apparaît dans le YAML, le Python,
le Bash et les tests. Aucun serveur de langage ne fait le lien entre ces fichiers.
*À faire* : remplace *toutes* les occurrences de =api_url= par =base_url=
(=api_url_fallback= aussi) dans tout le projet, en une seule fois.
*Vérifier* : =python3 verifier.py 4.2=

*** Comment faire (la technique la plus puissante d'Emacs)
1. =s-F= puis tape =api_url= : toutes les lignes s'affichent.
2. =C-.= (embark, « agir sur… ») puis =E= (exporter) : les résultats deviennent un
   buffer normal.
3. =C-c C-p= : ce buffer devient *modifiable* (wgrep).
4. Modifie les lignes comme du texte normal. Par exemple : descends sur la *première
   ligne de résultat* (=C-n=), puis =M-%= =api_url= =RET= =base_url= =RET= et =!=
   (tout remplacer). L'en-tête du buffer n'est pas modifiable, d'où le départ sous lui.
5. =C-c C-c= : les modifications sont écrites dans *tous les fichiers* d'un coup.
   =C-c C-k= aurait tout annulé.
- Tu vois toutes les lignes avant de valider. Tu peux aussi n'en modifier que certaines.
- Alternative plus simple : =C-x p r= (remplacer dans le projet), avec confirmation
  à chaque occurrence (=y= / =n= / =!=). Elle passe aussi dans =EXERCICES.org= et
  =verifier.py= : réponds =n= pour ces deux fichiers. =s-F=, lui, les ignore (fichier =.ignore=).
